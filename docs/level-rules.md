# 2D 瓶子堆关卡规则

来源：参考项目 `bottlegame/docs/level-rules.md`。完整原文保存在 [level-rules-reference.md](level-rules-reference.md)。本文件是当前 2D 普通关卡的实施版本，舍弃了 3D 相机、重力沉降、每日挑战和物理堆高等专属规则。

## 基础规则

- 五个手持位置，开局两个空瓶、三个空位。
- 每瓶四份。倒出顶部连续同色段；目标有空间就能接，不要求顶部同色。
- 四份同色装满后收走该瓶，释放位置。
- 失败：五格占满，手里每种颜色总数都不足四份。
- 胜利：瓶子堆取空，手里的水全部归色消除。
- 遮挡以 2D 屏幕轮廓为准：可见面积达到 90% 才能拿。取走后重新计算可见集合；不使用隐藏的强制取瓶顺序。

## 配色必须遵守的约束

1. 每种颜色总份数是四的倍数。30 瓶、五色对应 120 份，本关每色 24 份。
2. 开局不能有单色满瓶。每瓶至少两种颜色。
3. 单瓶内容保留不同复杂度：双色可为 3:1 或 2:2；三色为 2:1:1；四色为 1:1:1:1。
4. 同一种份数组合也必须有排列变化，如 AABB、ABAB、ABBA；单独的一份也可在顶部、底部或中间。
5. 由浅入深是整体趋势。早期保留缓冲；中后段提高三色、四色比例，同时保留一些简单瓶。按实际几何暴露波次检查，不按画面上下硬分区。
6. 修改颜色、瓶型、位置、缩放或角度，都必须重新验解。只换颜色名称不影响已验证的路径。
7. 难度和容错不能用解法步数或搜索节点数直接排名。开局连续取三瓶的即时安全率也不是全局通关率。

## 当前 30 瓶版本

- 直接采用上游普通关卡 003 的全部颜色内容：12 只双色、16 只三色、2 只四色。
- 每色 24 份；所有瓶子开局均混色。
- 保存的源数据：`docs/level-source-003.json`；最终数据：`heap-level.js`。
- 原始解法的取瓶先后用于安排初始绘制深度，再用独立 2D 轮廓计算验证整条路径；运行时始终按真实遮挡拿取，其他露出的瓶子同样可以取。
- 姿态包括正放、侧放、倒放；当前首页统一使用 bottle04 杯型，先前的三瓶型版本独立保存在 `index02.html`。摆在堆中时，水与瓶身一同旋转；拿到手里、执行倒水时才计算水平自由液面。
- 布局在统一设计坐标中计算，再整体缩放到不同手机尺寸，保证遮挡判定与画面一致。
- 液体的四份视觉高度仍以原始瓶型为统一基准；不同轮廓倾斜时保留各份实际占用面积。
- 初始可拾取 9 瓶。按实际暴露先后分成三个各 10 瓶的阶段，平均颜色数为 2.5 / 2.7 / 2.8。保留局部交错，不保证任意拿取顺序下难度单调。
- 728 种合法的连续三瓶开局中，668 种不会立刻失败；每步均匀选择可拾瓶时即时安全率约 91.74%。这不保证之后任意操作都能通关。
- 126 步完整合法路径在新 2D 几何下通过验证；关闭自动消除辅助，只在一只瓶子真正装满同色时消除。

## 修改与验证

1. 改配色或摆放后运行 `node scripts/build-30-level.cjs`，重新生成候选与分析。
2. 运行 `node --test tests/heap-rules.test.cjs` 检查份数、颜色复杂度、遮挡、失败判定和整条解法。
3. 用浏览器真实点击重放，检查可取瓶子实际点得到、空位及时释放、不会溢出。
4. 检查 320/390/480px 手机宽度，堆叠轮廓没有出屏，拿瓶和倒水不会被透明按钮框拦截。

## 自动消除辅助

- 页面底部的白底黑字开关默认关闭，每次重新进入或重开都恢复关闭。
- 开启后，手里某种颜色累计达到四份，即使埋在不同水层里，也会自动汇集四份并释放一个瓶子。其他颜色会重新分配到剩余瓶子，保持总份数且不超过每瓶四份。
- 优先选只含目标颜色的瓶子、空瓶，或杂色最少的瓶子作为汇集瓶，沿用参考实现。
- 先完成已接受的手动倒水队列，再执行自动汇集。关闭开关会完成当前这一次消除，之后停止自动连续消除。
- 自动汇集时瓶子不飞来飞去，只让水层原地涨落；随后统一播放约 220ms 的高光扫过、三颗小星闪光和淡出。手动凑满同色也使用同一消除效果。
- 完整关卡的 126 步有解认证仍按辅助关闭的规则进行。另有开启辅助、只按已认证拾取顺序拿瓶即可完整通关的浏览器回归。

## bottle04 椭圆水面版本（2026-11-05）

- `bottle04-1.svg` 是带颜色和椭圆分层的参考；`bottle04-2.svg` 提供同一瓶形的水域遮罩。
- 四份水的主体基准仍等高。层间界面下凸，最上方另加浅色椭圆，因此顶层在中心位置比下方单层多出一个完整椭圆的视觉厚度。这是透视表现，不增加第五份水。
- 堆中椭圆与瓶子一同旋转；倒水时椭圆深度随倾角减小，回到水平自由液面的算法。水域遮罩有细笔刷轮廓，各色交界再加轻微纸面扰动。
- 改瓶形后先用 `scripts/export-bottle-shapes.cjs` 重新导出 SVG 轮廓，再运行 `scripts/build-30-level.cjs` 重新验证遮挡。脚本通过 `PLAYWRIGHT_PACKAGE` 指定本地 Playwright 包位置。
- 本次保留原30瓶的全部颜色内容和126步解法，针对新杯形重新生成摆放并通过2D规则验证；初始可拾9瓶。
