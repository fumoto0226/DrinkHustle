# 线条效果制作记录

记录日期：2026-11-05。本文记录各效果实装时的参数，作为后续制作、对比和恢复的基准。首页 `index.html` 当前使用效果二；`index02.html` 的独立原瓶型副本保留效果一。效果一章节中的参数是其冻结版本，不随后续首页调整而改变。

## 线条效果一

### 视觉目标

保留原 SVG 的手绘轮廓，在笔画转折附近形成自然的加重与舒缓过渡；直线部分保持相对平顺，最细处也有连续的墨色。边缘有少量纸面毛糙，但不依靠密集抖动表现手绘感。

瓶子的黑色轮廓和水域边缘采用同一套笔刷轮廓算法，按用途使用不同宽度。水的边缘保持自身颜色，不加黑色描边。

### 对应文件与冻结副本

- 效果一算法：`docs/line-effects/effect-01/ink-stroke.js`；Index02 的运行副本为 `index02-assets/ink-stroke.js`。
- 效果一新杯型记录时的调用及 SVG 滤镜位于 `heap-game.js`；Index02 保留其原瓶型调用和独立资源。
- 瓶型宽度修正：`bottle-art.js` 的 `inkScale`。
- 本效果的算法冻结副本：[effect-01/ink-stroke.js](line-effects/effect-01/ink-stroke.js)。
- 本效果的参数冻结副本：[effect-01/settings.json](line-effects/effect-01/settings.json)。

冻结副本不参与页面运行，用于以后修改效果二时对照、恢复效果一。

### 1. 沿原 SVG 路径采样

使用 `getTotalLength()` 和 `getPointAtLength()` 沿路径取点。

| 参数 | 当前值 | 作用 |
| --- | --- | --- |
| 采样步长 `step` | `0.5` SVG 单位 | 保持曲线轮廓连续 |
| 最少分段数 | `16` | 短路径也有足够采样 |
| 切线采样臂长 | 约 `±2` SVG 单位 | 由相邻点计算切线与法线 |
| 转折检测臂长 `curvArm` | `3` 个采样点 | 约 `±1.5` SVG 单位 |

闭合路径首尾循环取样；开放路径在端点处截断取样。

### 2. 根据曲率决定笔锋位置

对前后切线做点积，计算转折强度：

```js
curvature = Math.max(0, 1 - dot(tangentBefore, tangentAfter));
turnSign = Math.sign(cross(tangentBefore, tangentAfter));
```

转折越明显，局部笔画越容易加重。`turnSign` 用于区分转弯方向，让内外两侧的笔画扩张可以有轻微差异。

对转折强度和方向加权值做高斯平滑：

| 参数 | 当前值 |
| --- | --- |
| 平滑半径 `radius` | `20` 个采样点 |
| 标准差 `sigma` | `7` 个采样点 |

这一步让加重区域沿相邻线段逐渐展开，避免转角突然出现一块粗墨。

### 3. 叠加固定种子的轻微宽度扰动

| 参数 | 当前值 |
| --- | --- |
| 基础宽度 `BASE_WIDTH` | `2.0` |
| 转折加重幅度 `SWELL` | `2.1` |
| 宽度扰动幅度 `JITTER_AMP` | `0.4` |
| 转折强度增益 `BEND_GAIN` | `6` |
| 内外侧偏置增益 `BIAS_GAIN` | `6` |
| 偏置相位 `BIAS_SWAY_OFFSET` | `0.37` |
| 扰动控制点数量 | `max(4, round(pathLength / 22))` |

每个控制点的扰动值为 `rand() * rand()`，相邻值通过 `f*f*(3-2*f)` 平滑插值。闭合路径最后一个值与第一个值一致。

随机数生成规则固定：

```js
state = ((seed + 1) * 7919) >>> 0;
state = (Math.imul(state, 1664525) + 1013904223) >>> 0;
random = state / 4294967296;
```

每只瓶子、每条路径使用不同种子：`seedBase * 11 + pathIndex * 3`。因此不同瓶子的细节略有区别，同一只瓶子的纹理在动画中保持稳定。

这里的基础采样和扰动控制点是等距的，随机的是扰动强度；主要笔锋随原路径转折出现，并不是每隔固定距离就加粗一次。

### 4. 生成真正有宽度变化的填充轮廓

先计算对称宽度、转折加重和内外侧偏置，再沿法线向两侧扩张：

```js
bend = Math.min(1, smoothCurvature * 6);
symmetric = 2.0 + jitter * 0.4;
swell = bend * 2.1;
sway = shiftedJitter * 2 - 0.3;
side = clamp(smoothedBias * 6, -1, 1) * sway;

inner = (symmetric / 2 + swell * (0.5 + 0.35 * side)) * widthScale;
outer = (symmetric / 2 + swell * (0.5 - 0.35 * side)) * widthScale;
left = point + normal * inner;
right = point - normal * outer;
```

正向连接左侧点，再反向连接右侧点，闭合成填充路径。坐标保留两位小数。黑色瓶子轮廓使用 `fill="black"`，粗细来自填充轮廓本身。

开放路径另外使用端部渐细：`taper = min(1, 0.4 + t*5, 0.4 + (1-t)*5)`；端部仍保留基础宽度的一部分，避免收笔细到断线。

### 5. 当前首页的使用参数

调用方式：

```js
inkPaths(outlinePaths, bottleIndex, { widthScale: 0.65 });
inkPaths([waterMaskPath], bottleIndex + 101, { widthScale: 0.38 });
```

- **瓶子黑线**：当前 `bottle04` 使用 `inkScale: 0.65`，适配 `54 × 80` 的短杯形 SVG。
- **水域外沿**：原始灰色遮罩路径与 `widthScale: 0.38` 的笔刷轮廓共同组成裁剪区域，得到轻微不规则的彩色边缘。
- `widthScale` 缩放笔画扩张宽度，不改变原 SVG 的中心路径和瓶形比例。

### 6. 最后一层纸面纹理

瓶子黑线生成填充轮廓后，叠加轻微 SVG 位移滤镜：

| 参数 | 黑色瓶子轮廓 | 彩色水域 |
| --- | --- | --- |
| `feTurbulence.type` | `fractalNoise` | `fractalNoise` |
| `baseFrequency` | `0.08` | `0.48` |
| `numOctaves` | `2` | `2` |
| `seed` | `17 + bottleIndex*7` | `23 + bottleIndex*5` |
| `feDisplacementMap.scale` | `1.8` | `0.42` |
| `xChannelSelector` | `R` | `R` |
| `yChannelSelector` | `G` | `G` |

两个滤镜都采用 `filterUnits="userSpaceOnUse"`、`color-interpolation-filters="sRGB"`；区域在 SVG 四周各扩展 `6` 个单位，避免笔触边缘被裁掉。

水域滤镜放在完成内部裁剪之后、瓶口范围裁剪之内，处理彩色水域的外沿、层间弧线和椭圆水面。水面椭圆本身属于瓶型透视表现，其几何参数单独保存在 `bottle-art.js`，不作为笔刷宽度使用。

### 7. 稳定性与复用约定

- 几何分析按原路径字符串缓存；同一路径只分析一次。
- 黑线轮廓和水域笔刷裁剪在每只瓶子创建时生成，动画中不重新随机化。
- 瓶子移动、旋转、倒水时，笔触随瓶身一起变换。
- 被遮挡时的淡色只是显示状态，当前水和黑线透明度分别为 `0.56`、`0.58`，不改变本效果的几何规则。
- 调整效果二时，以本节参数与冻结副本作为效果一基准。

## 线条效果二

2026-11-05：按用户提供的 Billybutton.brush 参数改为密集叠印的实心矢量笔刷，仅用于 index.html。效果一与 index02 的独立资源不变。

导出文件引用 Procreate 内置 `Alpine_Shape.png`，但没有携带图片。本实现用近似的不规则圆形矢量笔尖模拟，不能声称完整复刻原笔刷。原始归一化数值的百分比不保证等于 Procreate 界面显示，网页中的参数映射是近似的。

- 基础宽度 3.55，瓶子缩放 0.65，水域边缘缩放 0.38。
- 间距 0.0715088695；间距变化 0.4776262045。
- 横向抖动 0.0727313533；纵向抖动 0.1099295318。
- 大小变化 0.2112026513；圆度变化 0.1350364685，横向圆度变化 0.0842589661。
- 随机旋转、横纵翻转；所有笔尖统一绕向并以 nonzero 填充，重叠处保持实心。
- 无额外纸张颗粒或透明侵蚀；固定种子，移动和倒水时不重新随机。
- 几何与完成的笔画按路径、种子及宽度缓存。
- 算法副本：[effect-02/ink-stroke.js](line-effects/effect-02/ink-stroke.js)。
- 参数副本：[effect-02/settings.json](line-effects/effect-02/settings.json)。

### 放大笔触与自然断笔

笔尖间距额外乘 2.4，横向抖动乘 1.65，增加沿路径连续变化的两组线宽起伏，避免密集叠印掩盖细节。瓶型尺寸不变。

用 ±1.6 单位的路径方向变化识别明显拐角，转折阈值 0.32，相邻候选至少间隔 5 单位（包含闭合首尾）。每个拐角独立以 22% 概率产生断笔。断口半长为笔触宽度的 7–12%，位置有 ±0.3 的偏移，外侧在 0.35 倍笔触宽度范围内逐渐收细。限制笔尖半径，防止叠印盖住断口。水域使用 cornerBreaks:false，保持完整。

2026-11-05 微调：两组整体线宽起伏幅度由 0.17/0.08 降到 0.07/0.035，保留细碎笔尖变化和毛边。断笔概率降为 22%，缩短断口和收细过渡。

### 启动性能优化

每个不同源路径按 0.12 SVG 单位预采样，拐角检测和全部瓶子的笔尖位置改用共享插值查询。生成笔尖时同步保存实际舍入坐标的上下界，首页布局直接读取边界元数据，避免再用正则遍历全部笔尖坐标。保留原笔尖数量、随机序列和断笔参数。

30 瓶圆形模拟中原生路径查询从 124797 次降至 1668 次，顶点偏差不超过 0.001 SVG 单位；这不是浏览器加载时间测量，实际首屏耗时待实测。

### 彩色水边

水域遮罩改成沿法线扰动的闭合轮廓；各水层上沿和下弧边加入固定细碎起伏；浅色水面椭圆改成 192 点闭合毛边。保持原颜色且无断口。动态边缘采用轻量几何近似笔刷毛边，避免逐帧叠印、路径测量与缓存不断增长。倾斜时填充覆盖范围按 SVG 对角线扩展。
